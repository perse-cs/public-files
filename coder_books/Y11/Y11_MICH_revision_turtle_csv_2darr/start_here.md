# Start here

This book revises three GCSE topics:

**Turtle graphics** - drawing with loops, selection and subprograms

**CSV files** - reading, searching, validating and writing comma-separated data

**2D arrays** - processing lists of lists and displaying them as neatly formatted tables

## How the book works

**Exercises** holds 12 tasks, four per topic, getting harder each time:

| Level | What you do |
|---|---|
| Trivial | Fix the errors, fill in the blanks, or put scrambled lines in order |
| Simple | Most of the code is given; complete the missing lines |
| Medium | You are given the task and write the code yourself |
| Hard | Several requirements at once, and you must split the problem into subprograms |

Press **Submit** to have your code auto-marked. A tick appears when every test passes.

**Model solutions** holds a worked solution to each exercise that you can run and read. Have a proper go at an exercise before you look!

## The program template

Every program follows the Edexcel GCSE template shown in the editor. Run it to try it out.

| Section | What goes in it |
|---|---|
| `# LIBRARIES` | `import` statements |
| `# CONSTANTS` | fixed values, named in `UPPERCASE` |
| `# GLOBAL VARIABLES` | every global variable, **initialised** with a starting value |
| `# SUBPROGRAMS` | functions and procedures, each starting by initialising its local variables |
| `# MAIN` | the main program |

Use meaningful variable names in camelCase (`numSquares`, not `n`), blank lines between sections and subprograms, and comments that explain **why** rather than repeating the code.
